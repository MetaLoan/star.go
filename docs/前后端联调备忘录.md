### 事件影响值计算

```javascript
// 取事件对关系维度的正向影响（因为 Pluto Conjunction Venus 主要影响关系）
const impactValue = event.impact.relationship;
// 或取总体影响

// 显示格式
```

### 事件剩余时间计算

```javascript
// event.endTime 是事件结束时间
const now = new Date();
const endTime = new Date(event.endTime);
const diffDays = Math.ceil((endTime - now) / (1000 * 60 * 60 * 24));

if (diffDays > 0) {
  return `Ends in ${diffDays} days`;
} else if (diffDays === 0) {
  return `Ends today`;
} else {
  return `Ended`;
}
```

### 影响维度标签计算

```javascript
function getPrimaryDimension(impact) {
  const dims = [
    { key: 'career', label: 'Career', value: impact.career },
    { key: 'relationship', label: 'Love', value: impact.relationship },
    { key: 'health', label: 'Health', value: impact.health },
    { key: 'finance', label: 'Wealth', value: impact.finance },
    { key: 'spiritual', label: 'Spiritual', value: impact.spiritual }
  ];
  
  // 按绝对值排序，取最大的
  dims.sort((a, b) => Math.abs(b.value) - Math.abs(a.value));
  const primary = dims[0];
  
  return {
    label: primary.label,
    arrow: primary.value > 0 ? '↑' : '↓',
    value: primary.value > 0 ? `+${primary.value.toFixed(1)}` : primary.value.toFixed(1)
  };
}
```

```javascript
  const signIndex = Math.floor(cusp / 30);
```

## 五、完整前端调用流程

### 5.1 应用启动

```javascript
// 1. 健康检查
const health = await fetch('/health').then(r => r.json());
if (health.status !== 'ok') throw new Error('Server not ready');

// 3. 存储用户数据
localStorage.setItem('birthData', JSON.stringify(birthData));
localStorage.setItem('chart', JSON.stringify(chart));
```

### 5.2 日期切换

```javascript
async function loadDayData(date) {
  const birthData = JSON.parse(localStorage.getItem('birthData'));
  
  const response = await fetch('/api/v2/astro', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({
      birth: birthData,
      time: date.toISOString(),
      granularity: 'day',
      language: currentLanguage
    })
  });
  
  const { slot, meta } = await response.json();
  
  // 更新 UI
  updateScores(slot.scores);
  updateEvents(slot.events);
  updateGuidance(slot.guidance);
}
```

```javascript
async function switchGranularity(granularity) {
```

## 七、注意事项

### 7.1 时区处理

```javascript
// 出生数据使用出生地时区
const birthData = {
  // ...
  timezone: birthplaceTimezone  // 如伦敦为 0，北京为 8
};

// 查询时间使用用户当前时区
const queryTime = new Date().toISOString();  // 包含时区信息
```

### 7.2 缓存策略

- 本命盘数据（`/api/calc/chart`）可长期缓存，出生数据不变则不需重新请求
- 运势数据（`/api/v2/astro`）后端有缓存，相同参数会命中缓存
- 建议前端也缓存当天数据，减少请求

### 7.3 错误处理

```javascript
try {
  const response = await fetch('/api/v2/astro', options);
  
  if (!response.ok) {
    const error = await response.json();
    throw new Error(error.message || 'Unknown error');
  }
  
  const data = await response.json();
  // 处理数据...
  
} catch (error) {
  // 显示错误提示
  showToast(error.message);
  
  // 可选：使用缓存的旧数据
  const cached = localStorage.getItem(`astro_${dateKey}`);
  if (cached) {
    useCachedData(JSON.parse(cached));
  }
}
```

### 7.4 性能建议

1. **预加载**: 用户查看某天时，预加载前后几天的数据
2. **曲线优化**: 月曲线一次请求30天数据，避免重复请求
3. **本命盘缓存**: 星盘数据固定，只需请求一次
