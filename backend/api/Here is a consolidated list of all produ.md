Here is a consolidated list of all product development and design requirements for the Telegram MiniApp. All requirements are specified for mobile-first development, fully adhering to current mobile UI/UX best practices to deliver highly engaging and user-friendly interactions.

【Visual Design & Style】
- Core visual approach: pure white background, serif font, minimalistic layout.
- Main accent: dynamic "laser" gradients primarily in red, blue, purple, and yellow, used for highlights, interactive states, and brand differentiation.
- High visual clarity, clear hierarchy, and modern aesthetics for mobile app interfaces.
- All copy/content must be in English.

【Component Library & Effects (based on HeroUI/Next UI)】
- Button: various styles (primary/secondary/disabled), with visual and animated feedback on tap and hover.
- Text reveal animation: “ink diffusion” entrance and exit effects for key text (smooth, liquid-like appearance/disappearance).
- Tabs: seamless, animated transitions; visually distinct active state.
- Bottom navigation bar: smooth animated transitions, visually clear and persistent active highlight, and easily tappable on mobile.
- Back action for subpages: native-like touch area, optimal for iOS/Android usage habits.
- Top-level page titles and subtitles: distinct and structured layouts.
- Dynamic laser gradient effects: for buttons, chips, tags, and other accents—smooth, fluid, and responsive.
- Section subtitles, regular detail text, and emphasized detail text: clear hierarchy and mobile-friendly sizes.
- Article/heading text, tag titles, and tag subtitles (descriptions): standardized mobile-optimized typography.
- Tag states: strong hover and active indications.
- Input fields: includes placeholder text, validation indicators, with native-style date pickers and preset dropdowns.
- Switch (toggle) component: animated, with clear ON/OFF states.
- Standard modal dialogs: with animated entry/exit, titles, details, and configurable actions.
- Information messages (warning/success/insufficient balance): attention-grabbing color, centralized text, and prominent iconography.
- Full-page loading indicator: non-intrusive, visually engaging loading animations.
- Information input modals: support both single-step and multi-step forms; include date pickers, preset dropdowns, and elegant transitions between steps.
- Layer/dialog entry and exit animations (modals, input panels, bottom sheets, etc.).
- Multi-step progression indicator: clear current step, smooth animated transitions between steps/pages.
- Advanced line chart component (with HeroUI/Next UI): supports horizontal axis zoom, draggable viewport, point selection/interactivity, multiple lines and isolated view per line.
- Complete chat/dialogue component: message bubbles, avatars, input bar; supports animated message sending/receiving, and suggested replies for efficient interaction.

【Interaction and Animation】
- All animations must be smooth, high-performance, and follow mobile microinteraction standards.
- Tab switching, modal dialogs, and bottom navigation transitions are to have natural easing/transition effects for a premium feel.
- State changes (active, hover, error, disabled) must deliver clear visual and animated feedback.
- Warning/alert messages: visually highlighted, centered, never easily missed.

【Adaptation & Experience】
- Fully responsive/adaptive design for all mainstream mobile devices (iOS/Android, various screen sizes).
- All controls (buttons, inputs, tabs) sized and positioned for thumb-friendly mobile reach and single-handed use.
- Typography, spacing, and touch area strictly designed for mobile ergonomics.
- Step-by-step modals include progress indicators and smooth animated step transitions for an intuitive flow.
- Best practices in accessibility and usability (contrast, font size, interactive feedback, etc.) that meet mobile standards.

【Development & Delivery】
- Finalize and deliver a comprehensive UI/UX specification document after component library completion, supporting ongoing development and future design expansion.
- Follow and reference best practices inspired by leading mobile interfaces (e.g., 3ye frontend style) to achieve a unique pure-white minimal + laser-gradient look.
- Performance optimization is required to guarantee high frame rates and low-latency interactions on mobile.

For further interactive prototyping or detailed visual drafts, it is recommended to closely collaborate with UI/UX designers.
