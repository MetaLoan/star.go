# Internationalization (i18n)

## Overview

All API endpoints support multi-language responses through the `language` parameter.

## Supported Languages

| Code | Language | Status |
|------|----------|--------|
| `zh` | Chinese (Simplified) | ✓ Full support |
| `en` | English | ✓ Full support (default) |
| `ru` | Russian | ✓ Full support |

## Usage

Add the `language` parameter to any API request:

```json
{
  "language": "zh",
  "birth": { "year": 1990, "month": 5, "day": 15, ... },
  "date": "2026-01-16"
}
```

## Implementation

All translations are handled server-side using the `/backend/i18n` package:

- `i18n.go` - Core translator interface
- `translations.go` - Basic translations (planets, aspects, signs)
- `emotional_titles.go` - Psychological/emotional titles

To add new languages, extend these files with new translation maps.
