## 📝 三、文案质量标准

### 3.1 内容要求
1. **混合风格**：情感描述 + 实用建议
2. **维度关联**：明确关联到 5 个维度（事业、关系、健康、财务、灵性）
3. **正负性准确**：正面事件用积极语言，负面事件用建设性语言
4. **长度适中**：100-200 字（中文），50-100 词（英文）

### 3.2 格式要求
1. **Markdown 支持**：使用 `**粗体**` 强调关键词
2. **结构化**：包含"是什么"、"为什么"、"怎么做"
3. **多语言一致性**：三种语言的内容结构保持一致

### 3.3 技术实现
1. **Key 命名规范**：`planet1_aspect_planet2` 或 `planet_house_N`
2. **双向查找**：支持 `planet1_aspect_planet2` 和 `planet2_aspect_planet1`
3. **兜底机制**：所有事件类型都有通用 fallback 文案
